## 道路統計年報との検算

比べるのは全国計だけです。国道の番号は全国で一意なので、県別に割っても番号の取り違えは見つかりません。県別でしか答えられないのは都道府県道のほうで、そちらは[都道府県道の検算](#都道府県道の検算)にあります。

### 同じ言葉が別の物を指す

| 年報の言葉 | 中身 |
| --- | --- |
| 総延長 | 指定された路線の全延長。重用区間は路線ごとに数える |
| 重用延長 | 上級の路線に重複している区間 |
| 未供用延長 | 認定の告示はあるが供用開始の告示がない区間。海上区間を含む |
| 渡船延長 | 渡船施設があり供用開始されている区間。一般国道では 0 |
| 実延長 | 総延長から重用・未供用・渡船を引いた値 |
| 旧道 | 改築前の元の道路。実延長の内数 |

年報の 実延長 には未供用が入りません。地図の重複排除の延長には工事中も未開通も海上も入ります。同じ物を数えているのは、年報の 総延長 − 重用延長 と、地図の重複排除の延長です。

旧道はこの表に入りません。年報の 旧道 は 実延長 の内数で、地図も旧道を除外せずに数えます。どちらの合計にも入るので、上の −472.3 km は分類の差であって延長の差ではありません。地図が旧道と判定できていない区間は、旧道でない現役の国道として同じ延長に入っています。

#### 上下線分離 +9,705.3 km

上下線を別々に描いた道は、台帳では 1 本です。同じ番号の道が側方 40 m 以内を並んで走り、どちらも一方通行である長さを測り、その半分を二重計上としました。

閾値で答えは動きません。40 m を 25 m にすると 9,363.0 km、60 m にすると 9,822.4 km です。

裏取りが 1 つあります。年報は 実延長 のうち中央帯を設置した延長を 7,498.2 km と別に数えています。上下を帯で分けることと、OSM が道を 2 本に分けることは、ほぼ同じ事実を指します。測った 9,705.3 km のうち平面国道由来は 7,374.9 km で、この値に近い数です。残りの 2,330.4 km は自動車専用道路由来です。

#### ランプ・連結路 +627.6 km

`highway=*_link` の 3,451 アークです。ランプは台帳の路線延長ではありません。

#### 工事中・未開通 +575.9 km

地図は 941.5 km、年報の未供用のうち陸上は 365.5 km です。差のうち、測って原因が付いたのは次の 2 つです。

- 供用中の同番号の道と並んで工事中のもの 87.6 km
  - 改築であって、元の道は台帳にすでに入っている
- 工事中どうしで上下線に分かれているもの 109.3 km

残る 379.0 km は下の残りに入ります。OSM の `construction` は、告示に載る前の事業中の道にも付きます。

#### 並行する同番号の道 +134.5 km

側道のように、同じ番号を持つ道が本線と並んで走るものです。上下線分離と違い、どちらか一方は一方通行ではありません。

#### 海上区間 −196.5 km

年報 1,953.1 km に対し、地図は 1,756.7 km です。リレーションに含まれる航路しか入っていません。既知の制約です。

### 説明できていない残り

1,296.6 km、差の 10.9% です。うち 379.0 km は上の工事中・未開通の残りで、917.6 km は供用中の車道の残りです。

供用中の車道の残りには、次のものが入るはずですが、量は測っていません。

- 高速自動車国道と重なる一般国道
  - 年報は表8の重用延長に寄せ、高速自動車国道の側(表5)で数える
  - 地図は国道どうしの重用しか数えないので、この区間が残る
- 上下線が 60 m より離れている区間
- 国道番号を持つが台帳の路線延長ではない道
- 指定の痕跡が OSM から消えた旧道
  - 年報は数え、地図は持たない
  - 番号もリレーションも名称も外されると復元できない

### 重用の復元

年報の重用延長 11,562.9 km が物差しです。地図は 9,187.5 km を復元しました。79.5% です。

| 内訳 | km |
| --- | ---: |
| 国道と重用する区間 | 3,924.8 |
| 県道どうしの重用 | 5,262.7 |
| 合計 | 9,187.5 |

| 種別 | 年報 | 地図 | 復元率 |
| --- | ---: | ---: | ---: |
| 主要地方道 | 4,606.7 | 3,930.9 | 85.3% |
| 一般都道府県道 | 6,956.2 | 5,256.6 | 75.6% |

国道と重用する区間はリレーションからしか取れません。OSM はその区間を `highway=trunk`・`ref=国道番号` で描き、県道の指定はルートリレーションにしか残さないためです。復元した 3,924.8 km は way 9,151 本、実長 3,746.6 km ぶんです。

県道どうしの重用にリレーションは不要です。`ref=18;30` のように way 自身が二つの番号を持てば、そこから読めます。

79.5% は、issue #95 と #98 が上限として挙げている 59.8% / 40.8% と矛盾しません。別の量だからです。

| 量 | 何の割合か |
| --- | --- |
| 59.8% / 40.8% | 候補 way のうち、都道府県道のリレーションが抱える本数の割合 |
| 79.5% | 年報の重用延長のうち、地図が復元できた延長の割合 |

リレーションの網羅を、同じ集合について本数と延長の両方で測りました。

| 格 | way | 延長 |
| --- | ---: | ---: |
| primary | 75,654 / 128,404 (58.9%) | 37,126.3 / 60,843.2 km (61.0%) |
| secondary | 61,522 / 152,773 (40.3%) | 33,636.9 / 72,617.8 km (46.3%) |

延長のほうが本数より高い値です。長い way ほどリレーションに入っている、とは言えます。ただし差は primary で 2.1 ポイント、secondary で 6.0 ポイントで、79.5% との開きを説明する主因ではありません。

主因は、重用の半分以上(5,262.7 km)がリレーションを必要としないことです。リレーションが上限になるのは国道と重用する区間だけです。

上下線分離には裏取りがあります。年報は実延長のうち中央帯を設置した延長を 4,399.0 km と別に数えています。測った 5,121.5 km はそれより +16.4% です。中央帯は幅を持つ構造物で、OSM は塗り分けただけの分離帯でも way を分けるので、地図の側が大きく出るのは筋が通ります。

工事中・未開通は地図が 191.5 km、年報の未供用のうち陸上は 1,552.4 km です。地図が 1 割しか持ちません。年報の未供用は認定の告示だけがあって道がまだ無い区間を含みますが、OSM はそこに何も描きません。描いても番号を持たないので、候補になりません。

### 説明できていない残り

供用中の車道で −2,043.7 km、工事中・未開通で −1,390.3 km です。どちらも地図のほうが短い側の残りです。合わせて −3,434.0 km、年報の 131,395.4 km に対して 2.6% です。

残りは両方とも負、つまり地図が短い側です。だから残りを説明しうるのは、地図が持っていない道です。次の物が入るはずですが、量は測っていません。

- 番号もリレーションも持たない県道区間
  - `ref` を持たず、`network=JP:prefectural` のリレーションにも入っていない way
  - OSM に道はあるが、県道であるという主張がどこにも無い
- 番号が数字だけで書かれていない way
  - `ref=秋田県道41号` のような書き方は、番号の読み取りを通りません
- primary・secondary 以外の格で描かれた県道
  - `tertiary` や `unclassified` の県道は候補になりません
- OSM に道そのものが無い区間
  - 量は次の節で N13 と突き合わせて測ります

上下線が 40 m より離れている区間は、この残りを説明しません。探りが届かず二重計上として引かれないので、残りを正の側へ押し上げる向きにしか働かないためです。

工事中・未開通の残りは、上のとおり年報の未供用に地図が対応する物を持たないぶんです。

### 番号が県内で妥当か

番号は県の中でしか一意でないので、番号が妥当かどうかは県を決めてからでないと訊けません。台帳の側は幅でしか持てないので、幅から外れた県を報告します。

| 向き | 県 | 意味 |
| --- | ---: | --- |
| 幅の中 | 19 | — |
| 上限を超えた | 16 | その県に無い番号を地図が持っている |
| 下限に届かない | 12 | 路線が丸ごと地図に無い |

上限を超えた側は、奈良県が 174 に対し 164(+10)、岩手県が 239 に対し 233(+6)、山口県が 265 に対し 261(+4)と続きます。`ref` の打ち間違い、市町村道への県道番号の付与、県境を跨いだ way の寄せ間違いのどれかです。

下限に届かない側は、東京都が 252 に対し 286(−34)で突出し、宮崎県 −6、長野県と群馬県が −4 と続きます。

東京都は二つの実測が噛み合います。路線の数は 34 足りないのに、延長は +25.6% 多いのです。路線の数は少ないが、1 本あたりを重複して描いている、ということです。上下線分離 650.5 km を引くと残りは −43.3 km(−1.8%)になります。取りこぼした 34 路線ぶんの延長はここに含まれるはずですが、年報は路線ごとの延長を持たないので、そこまでは詰められません。

どちらが誤りかは判定の仕事です。ここでは向きと量だけを出します。

### 種別と道路の格

主要地方道と一般都道府県道を分けるのに使ったのは番号です。使わなかった格のほうを見張りに回します。

| --- | ---: | ---: |
| `primary` なのに一般都道府県道の番号 | 669 | 192.2 |
| `secondary` なのに主要地方道の番号 | 42 | 17.0 |

### N13 との突き合わせ

年報との差は、地図が短いことを言えても、その短さがどこにあるかは言えません。国土数値情報 N13(道路)は地理院地図と出どころを共有する独立した資料で、路線番号は持ちませんが「ここに都道府県道が在る」ことは述べます。道路分類 都道府県道(rdCtg=2)と候補を突き合わせました。

見るメッシュは、47 の bbox が覆う物と候補が触れる物の和です。どちらも道のデータから来るので、道が 1 本も無い島は分母から落ち、被覆率はそのぶん高く出ます。N03 が陸だと述べるメッシュと突き合わせると、差は 21 メッシュです。沖ノ鳥島・南鳥島・硫黄島・鳥島などの無人島と北方領土でした。

逆向き(近くに N13 が無い旧道のアーク)は測っていません。生成物の旧道フラグを要求するので、判定より後にしか立てられません。

### 低ズームの属性を減らした効き

都道府県道の z0-7 だけを、属性を変えて切り直して測りました。簡略化の閾値はどれも 3 で、線の形は同じです。数字は z0-7 の最大タイルです。

| 落とした属性 | 最大 | 差 |
| --- | ---: | ---: |
| なし | 2,322 kB | — |
| `label` | 2,192 kB | −130 kB |
| `name` | 2,064 kB | −258 kB |
| `km` | 2,158 kB | −164 kB |
| `id` | 1,835 kB | −487 kB |
| `label`・`name`・`km`・`src`・`id` | 1,258 kB | −1,064 kB |

MVT は属性の値を層ごとの辞書で持つので、効くのは値の種類の数です。`id` が一番大きいのは、アークごとに違う値だからです。`refs`・`kind`・`rank`・`pref` のように取りうる値が少ない属性は、辞書の外にほとんど出ません。

配るのは最後の行です。落とした五つのうち `label` は z8 より下では読まれず(`route-labels` の `minzoom` が 8)、残る四つを読むのはポップアップだけです。

`--max-old-space-size` を下げていって、通る値と落ちる値を測りました。この節の数は node 26.7.0・Windows で測ったものです。

| `pack_web.mjs`(国道) | 640 MB | 512 MB |

かつては低ズーム索引が山でした。z0 から split-1 までを一度に作り、書き終えても抱えたままだったからです。今は 1 段ずつ作らせ、書き終えた段から捨てます(`pipeline/tiles.mjs`)。都道府県道の下限はこれで 1,280 MB から 1,024 MB へ下がりました。国道の下限は下がりません。山が消えても、47 県ぶんの GeoJSON と結合した弧が最後まで残り、そこに深いセルのピラミッドが重なるところで下限が決まるためです。

## 既知の制約

- bbox で切っているため隣県が食み込む
  - 行政界でのクリップは未実装
  - 路線数には食み出しで入った隣県の路線を含む
- 東京都の bbox は本土だけ
  - 都域は小笠原・南鳥島・沖ノ鳥島に及び、測ると 15.8x18.5 度になる
  - その矩形は愛知から和歌山までを飲み込み、裏取りが効かなくなる
  - 外した島々に国道は無いことを、取りこぼし検査が毎回確かめる
- 台帳の起終点は全路線には付かない
  - 港湾・空港は市区町村でないので座標を当てられない
  - 市区町村内に端点が無い路線は座標を持たない
  - 環状路線は起点と終点を区別できない
- 地図が描く起終点は暫定
  - bbox の縁で切れた端点は除外している
- 海上国道は部分的
  - リレーションに含まれる航路だけが入る
  - 車道と紛れないよう破線で描き、表示は個別に切り替えられる
