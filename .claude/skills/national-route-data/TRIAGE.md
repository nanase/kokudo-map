# 不具合の検出と切り分け

国道は起点から終点までの鎖です。データが欠ければ鎖が切れます。切断はスクリプトが断定できる事実なので、目視も推測も要りません。

## 監査を走らせる

```sh
uv run scripts/audit.py nagano             # 怪しい路線を順位付けする
uv run scripts/audit.py nagano --route 418 # 個別に切断箇所を列挙する
```

パスはスキルのディレクトリからの相対です。

## 隙間の長さで原因を分ける

| 隙間 | ほぼ確実な意味 |
| --- | --- |
| 50 m 未満 | ノードが共有されていない。道路の欠落ではない |
| 50 m 〜 2 km | 短い接続の欠落、バイパス分岐、工事中区間の境界 |
| 2 km 超 | 区間の欠落、または本物の断絶 |

## 判断フロー

監査は各隙間について、その番号を主張する way が生 OSM にあるかを示します。ここで三つに分かれます。

1. 主張する way があるのに出力に無い
   - 判定ルールのバグ
   - 一箇所直せば全国に効く
2. 主張する way が無い
   - OSM 自体に無い
   - ルールを変えても出てこない
3. 端の区間が `construction`
   - 工事中区間の境界
   - 正常なので触らない

## 修正先を選ぶ

| 分類 | 修正先 |
| --- | --- |
| ルールのバグ | 判定スクリプトのルール |
| OSM の欠落 | OSM への投稿、または参照データとの突き合わせ |
| 本物の断絶 | 触らず、既知として記録 |

これまで見つかった不具合はすべてルールの修正で直りました。個別データの手当ては一度も必要ありませんでした。全国化しても増えるのは同じルール違反の再発であって、新しい判断ではありません。

## 誤検知しない既知の断絶

次は正常な切断です。欠落として扱いません。

- 点線国道
  - 未開通の峠越え、階段
- 海上国道
- 未開通の工事中区間
- 地域の bbox で切れた端点

## 直したら検証に足す

不具合を直したときは、同じ症状を捕まえる断定を検証スクリプトに追加します。直したことの証明が残り、再発に気づけます。

## OSM に無いものを見つける方法

OSM だけを見ていても分かりません。参照データが要ります。

- 国土数値情報 N13(長野県のみ実装済み)
  - 電子国土基本図由来で、地理院地図と同じ出典
  - 道路分類に国道があるが、路線番号は持たない
  - 我々の線でカバーされない国道を抽出すれば、地理院地図との差分になる
  - `uv run scripts/compare_n13.py <地域>` (`mise run compare-n13`) が実行する。取得・しきい値・他都道府県への広げ方は issue #1 にまとめてある
- 道路統計年報 表 26・27(未実装)
  - 路線別、都道府県別の実延長
  - 公式値と比べれば欠落量を路線ごとに定量化できる

N13 は路線番号を持たないので、抽出した欠落が何号かは自動で決まりません。隙間の両側が同じ路線なら推定できますが、交差点付近や分岐では判断が要ります。ここが人の出番です。
