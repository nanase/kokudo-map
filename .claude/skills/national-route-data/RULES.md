# 国道の判定ルール

判定は二つの問いに分かれます。根拠が違うので分けて扱います。

## 問 1 — そもそも国道か

次のいずれかを満たせば国道とみなします。

| 規則 | 条件 |
| --- | --- |
| a | 国道のルートリレーションが含んでいる |
| b | 名称が `国道N号` である |
| c | 国道の格で描かれ、他の路線リレーションが同じ番号を主張していない |

国道の格は `trunk`、`motorway`、およびそれらの `construction` です。

### 規則 c が必要な理由

ルートリレーションの整備は way の整備に大きく遅れます。長野南バイパスは国道 19 号で開通から数十年経ちますが、どのリレーションにも入っていません。規則 c は長野県で 107 アークを回収しました。

### primary を国道の格に入れない理由

番号だけの `ref` は国道の証明になりません。都道府県道も同じ形式を使います。長野県の範囲で計測した結果を示します。

| highway | 数字 ref を持つ way | 名称が国道で始まるもの |
| --- | --- | --- |
| secondary | 7,658 | 0 |
| primary | 3,305 | 0 |
| trunk | 86 | 31 |

primary 以下を規則 c の対象にすると、主要地方道を大量に取り込むだけで得るものがありません。

工事中の場合も同じです。`construction=primary` は一度この除外を迂回していました。全国で正しく入ったのは 5 本 1.6 km だけで、代わりに北海道道 39 号奥尻島線が国道 39 号として出ました。

### 都市高速の路線番号を国道番号として読まない

名称が `高速N号` の形で路線を指すとき、その N は都市高速道路の番号であって国道番号ではありません。首都高速 4 号新宿線は `ref=4` を持ちますが、国道 4 号は青森へ向かう道です。

全国で 303 本、207.7 km が該当しました。うち名称に 国道N号 を含むものは 0 件です。

裏取りはこれを止められません。裏取りが効くのは「その番号の路線が地域内に無い」ときだけで、国道 4 号は同じ都県に実在します。

規則 c だけがこの検査を通ります。リレーションが保証する way と、自ら 国道N号 を名乗る way は対象にしません。都市高速の一部は本当に国道の指定を受けており、その場合は名称がそう述べています。

名称に `高速N号` が無い都市高速の路線もあります。首都高速都心環状線は `ref=1` を持ちますが、名前には数字がありません。この場合は way が乗っているリレーションの `network` を見ます。`JP:` で始まらない `network`(`首都高速道路` など)は、`JP:prefectural` と同じ「別の主体が自分の番号を名乗っている」印です。全国で 34 のリレーションがこの形を持ち、33 件が実在の国道番号と衝突し、1,009 way に及びました。CASES.md 20 を参照してください。

## 問 2 — 何号か

次の和集合を取ります。

- その way を含む全リレーションの番号
  - 親リレーションから継承する
- 名称から読んだ `国道N号`
- `ref` のセミコロン区切りトークン

`ref` は必ずトークンとして照合します。`["ref"="8"]` のような完全一致は `ref=8;17` を落とし、重用区間がまるごと消えます。

リレーションと `ref` は互いを補います。長野県ではリレーションだけが持っていた指定が 186 アーク、`ref` だけが持っていた指定が 170 アークありました。片方だけではどちらの方向にも取りこぼします。

## 裏取り

way 自身の主張は、その番号の国道リレーションが同じ地域に実在する場合のみ採用します。名称由来の番号も同じ扱いです。地域内に路線が実在することを保証するのはリレーションだけです。

裏取りを省くと、県道の番号と OSM のタグ誤りがそのまま地図に出ます。実例は過去の判断の台帳にあります。

読み取り元にしてよい名称の欄は `name` と `name:ja` に限ります。`official_name` は信頼できません。

### 地域を広げてはいけない

「同じ地域」とは都道府県の箱です。ここを全国に広げると裏取りは裏取りでなくなります。

| 判定の範囲 | 保証された番号 | 濾せるもの |
| --- | --- | --- |
| 1 県 | 数十 | 県道の番号のほとんど |
| 全国 | 459 に近づく | 何も無い |

一般国道の番号は 1〜58 と 101〜507 から廃止 6 番を除いた 459 個です。全国で見ればどの番号もどこかに実在するので、全国をひとまとめに判定した瞬間に絞り込みは空振りします。

取得元を Overpass から pbf に替えても、判定の単位は都道府県のままにしてあります。取得は全国、判定は県です。

## 海上区間

「海上区間」と述べているものは航路として扱います。`route=ferry` が付いていなくても同じです。

読み取る欄は四つです。

| 欄 | 例 |
| --- | --- |
| `name`・`name:ja` | `国道58号(海上区間）` |
| `description`・`note` | `海上区間。フェリーは未供用。` |

名称だけでは足りません。全国で「海上区間」と書いた way は 34 本あり、内訳は次のとおりです。

| 書いてある欄 | way |
| --- | --- |
| 名称 | 20 |
| `description`・`note` だけ | 14 |

後者は前者の言い換えではなく、別の路線です。名称だけを読むと 16・28・30・42・57・259・317・324 号が車道のまま海の上に出ます。

`route=ferry` だけを根拠にすると、さらに 12 路線で破れます。全国で計測した結果を示します。

| 描かれ方 | アーク | 延長 |
| --- | --- | --- |
| 車道 | 20 | 1,390.5 km |
| 航路 | 2 | 63.3 km |

海上国道を破線で描くのは、車道と紛れさせないためです。295 km の直線を実線で引けば、走れる道に見えます。

## 未開通

`highway=planned`・`proposed` は道がまだありません。ルートリレーションの連続性を保つために引かれた直線で、走れません。

全国で 86 アーク、173.3 km あります。内訳は `proposed` が 76、`planned` が 10 です。最長は国道 360 号の 16.4 km（白山白川郷ホワイトロードが代替路）、次いで国道 274 号の 16.1 km（`description=国道274号不通区間`）です。

`kind` を分けず `road` のまま出すと、16 km の直線が実線で引かれ、走れる道に見えます。海上区間を破線にしたのと同じ理由です。

判定は海上区間のチェックより後に置きます。「海上区間」と書いた 34 本のうち 32 本は `highway=planned` を持ちます。`highway` を先に見ると、直したばかりの海上国道が未開通として上書きされます。

`highway` キー自体を持たず `proposed=trunk` や `planned=*` とだけ書く way もあります。「まだ無いが造ればこの格になる」という意味で、`highway=planned`・`proposed` とは別の書き方です。`highway` が無いのでこの判定はすり抜け、ただの `road` として実線で出ます。全国で計測すると、国道リレーションが保証する way のうちこの形は 1 件でした。CASES.md 22 を参照してください。

## 旧道

名称に「旧道」「廃道」「旧国道」を含むもの、または `historic:highway` を持つものは `former` フラグを立てて残します。除外しません。

- 指定解除まで法令上は国道
  - 解除は開通から数年遅れる
- 地理院地図も同じ理由で国道として描き続ける
- OSM は実態を反映して指定を外す傾向がある

`former` は名称・タグから立てる旧道フラグで、指定解除されたかどうかとは別の軸です。指定解除済みかどうかは `revoked` が独立に持ちます(issue #9)。ビルドの `apply_n13.py` が、`former` アークのうち N13(国土数値情報)の道路分類を突き合わせて指定解除を機械確認できたものにだけ `revoked=1` を書きます。確認できなかった(または確認していない)ものは `revoked=0` のままで、これは「指定解除されていない」ではなく「未確認」を意味します。判定の仕組みは `pipeline/compare_n13.py` のモジュール docstring、確認対象の絞り方は同ファイルの `ORPHAN_CANDIDATE_RATIO` を参照してください。

`historic:highway` は名称とは別の経路で同じ実態を述べます。way/152895667(長野・静岡県境)は `name` を持たず `old_name=国道152号`、`highway=residential`、`route=hiking` で、今もハイキングルートとして扱われています。それでも現行の「国道152号」本線リレーションのメンバーのままなので、名称だけを見る判定では旧道と分からず `former=0` の実線として出ます。全国で計測すると、国道リレーションが保証する way のうち `historic:highway` を持ち、かつ名称に旧道の語を含まないものはこの 1 件だけでした。CASES.md 21 を参照してください。

名称も `ref` もリレーション所属も `historic:highway` もすべて外された旧道は、OSM から復元できません。

## 自動車専用道路

`highway=motorway` の区間は `kind=expressway` にします。第二神明道路や神戸淡路鳴門自動車道のように、国道番号とは別に高速道路としての路線番号（`ref=E93;2` の `E93`、`ref=C3;475` の `C3` など）を持つ区間です。

車道であることは変わらないので、点線国道や工事中のような破線扱いにはしません。別の種別にするのは、平面交差の無い自動車専用の道路が、ふつうの平面国道とは別物として利用者の目に映るためです。表示・非表示を切り替える口も別に持たせます。

判定は `highway=motorway` かどうかで決め、`ref` の書式では決めません。全国で計測すると、`E` や `C` などの番号と `motorway` が両方揃うもの 6,321 本に対し、`motorway` だが番号の頭文字が違うもの（`C3`・`A1` など）が 6,619 本あります。`ref` の書式で判定すると後者を取りこぼします。逆に番号だけあって `motorway` でないもの 199 本は全て `construction=motorway`（建設中）で、`construction` の判定が先に効くので問題になりません。

## 出力の属性

| 属性 | 意味 |
| --- | --- |
| `refs` | 区切り文字で囲んだ指定路線。例は `,18,117,406,` |
| `refs_list` | 同じ内容の配列 |
| `n` | 重用数 |
| `kind` | `road`、`expressway`、`construction`、`unopened`、`foot`、`steps`、`ferry` |
| `src` | 判定の根拠。`relation`、`name`、`tag` |
| `former` | 旧道なら 1 |
| `revoked` | N13 で指定解除を機械確認できたら 1。0 は「未確認」であって「現役」の意味ではない |
| `updated` | その区間の最終編集日 |

`refs` を区切り文字で囲むのは、番号の照合を文字列包含で書けるようにするためです。`,4,` は `,14,` や `,400,` に誤マッチしません。
