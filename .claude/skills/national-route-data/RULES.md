# 国道の判定ルール

判定は二つの問いに分かれる。根拠が違うので分けて扱う。

## 問 1 — そもそも国道か

次のいずれかを満たせば国道とみなす。

| 規則 | 条件 |
| --- | --- |
| a | 国道のルートリレーションが含んでいる |
| b | 名称が `国道N号` である |
| c | 国道の格で描かれ、都道府県道のリレーションが主張していない |

国道の格は `trunk`、`motorway`、およびそれらの `construction` である。

### 規則 c が必要な理由

ルートリレーションの整備は way の整備に大きく遅れる。長野南バイパスは国道 19 号で開通から数十年経つが、どのリレーションにも入っていない。規則 c は長野県で 107 アークを回収した。

### primary を国道の格に入れない理由

番号だけの `ref` は国道の証明にならない。都道府県道も同じ形式を使う。長野県の範囲で計測した結果を示す。

| highway | 数字 ref を持つ way | 名称が国道で始まるもの |
| --- | --- | --- |
| secondary | 7,658 | 0 |
| primary | 3,305 | 0 |
| trunk | 86 | 31 |

primary 以下を規則 c の対象にすると、主要地方道を大量に取り込むだけで得るものがない。

## 問 2 — 何号か

次の和集合を取る。

- その way を含む全リレーションの番号
  - 親リレーションから継承する
- 名称から読んだ `国道N号`
- `ref` のセミコロン区切りトークン

`ref` は必ずトークンとして照合する。`["ref"="8"]` のような完全一致は `ref=8;17` を落とし、重用区間がまるごと消える。

リレーションと `ref` は互いを補う。長野県ではリレーションだけが持っていた指定が 186 アーク、`ref` だけが持っていた指定が 170 アークあった。片方だけではどちらの方向にも取りこぼす。

## 裏取り

way 自身の主張は、その番号の国道リレーションが同じ地域に実在する場合のみ採用する。名称由来の番号も同じ扱いである。地域内に路線が実在することを保証するのはリレーションだけである。

裏取りを省くと、県道の番号と OSM のタグ誤りがそのまま地図に出る。実例は過去の判断の台帳にある。

読み取り元にしてよい名称の欄は `name` と `name:ja` に限る。`official_name` は信頼できない。

## 旧道

名称に「旧道」「廃道」「旧国道」を含むものは `former` フラグを立てて残す。除外しない。

- 指定解除まで法令上は国道である
  - 解除は開通から数年遅れる
- 地理院地図も同じ理由で国道として描き続ける
- OSM は実態を反映して指定を外す傾向がある

名称も `ref` もリレーション所属もすべて外された旧道は、OSM から復元できない。

## 出力の属性

| 属性 | 意味 |
| --- | --- |
| `refs` | 区切り文字で囲んだ指定路線。例は `,18,117,406,` |
| `refs_list` | 同じ内容の配列 |
| `n` | 重用数 |
| `kind` | `road`、`construction`、`foot`、`steps`、`ferry` |
| `src` | 判定の根拠。`relation`、`name`、`tag` |
| `former` | 旧道なら 1 |
| `updated` | その区間の最終編集日 |

`refs` を区切り文字で囲むのは、番号の照合を文字列包含で書けるようにするためである。`,4,` は `,14,` や `,400,` に誤マッチしない。
