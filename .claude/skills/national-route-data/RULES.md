# 国道の判定ルール

判定は二つの問いに分かれる。根拠が違うので分けて扱う。

## 問 1 — そもそも国道か

次のいずれかを満たせば国道とみなす。

| 規則 | 条件 |
| --- | --- |
| a | 国道のルートリレーションが含んでいる |
| b | 名称が `国道N号` である |
| c | 国道の格で描かれ、都道府県道のリレーションが主張していない |

国道の格は `trunk`、`motorway`、およびそれらの `construction` である。

### 規則 c が必要な理由

ルートリレーションの整備は way の整備に大きく遅れる。長野南バイパスは国道 19 号で開通から数十年経つが、どのリレーションにも入っていない。規則 c は長野県で 107 アークを回収した。

### primary を国道の格に入れない理由

番号だけの `ref` は国道の証明にならない。都道府県道も同じ形式を使う。長野県の範囲で計測した結果を示す。

| highway | 数字 ref を持つ way | 名称が国道で始まるもの |
| --- | --- | --- |
| secondary | 7,658 | 0 |
| primary | 3,305 | 0 |
| trunk | 86 | 31 |

primary 以下を規則 c の対象にすると、主要地方道を大量に取り込むだけで得るものがない。

工事中の場合も同じである。`construction=primary` は一度この除外を迂回していた。全国で正しく入ったのは 5 本 1.6 km だけで、代わりに北海道道 39 号奥尻島線が国道 39 号として出た。

### 都市高速の路線番号を国道番号として読まない

名称が `高速N号` の形で路線を指すとき、その N は都市高速道路の番号であって国道番号ではない。首都高速 4 号新宿線は `ref=4` を持つが、国道 4 号は青森へ向かう道である。

全国で 303 本、207.7 km が該当した。うち名称に 国道N号 を含むものは 0 件である。

裏取りはこれを止められない。裏取りが効くのは「その番号の路線が地域内に無い」ときだけで、国道 4 号は同じ都県に実在する。

規則 c だけがこの検査を通る。リレーションが保証する way と、自ら 国道N号 を名乗る way は対象にしない。都市高速の一部は本当に国道の指定を受けており、その場合は名称がそう述べている。

## 問 2 — 何号か

次の和集合を取る。

- その way を含む全リレーションの番号
  - 親リレーションから継承する
- 名称から読んだ `国道N号`
- `ref` のセミコロン区切りトークン

`ref` は必ずトークンとして照合する。`["ref"="8"]` のような完全一致は `ref=8;17` を落とし、重用区間がまるごと消える。

リレーションと `ref` は互いを補う。長野県ではリレーションだけが持っていた指定が 186 アーク、`ref` だけが持っていた指定が 170 アークあった。片方だけではどちらの方向にも取りこぼす。

## 裏取り

way 自身の主張は、その番号の国道リレーションが同じ地域に実在する場合のみ採用する。名称由来の番号も同じ扱いである。地域内に路線が実在することを保証するのはリレーションだけである。

裏取りを省くと、県道の番号と OSM のタグ誤りがそのまま地図に出る。実例は過去の判断の台帳にある。

読み取り元にしてよい名称の欄は `name` と `name:ja` に限る。`official_name` は信頼できない。

### 地域を広げてはいけない

「同じ地域」とは都道府県の箱である。ここを全国に広げると裏取りは裏取りでなくなる。

| 判定の範囲 | 保証された番号 | 濾せるもの |
| --- | --- | --- |
| 1 県 | 数十 | 県道の番号のほとんど |
| 全国 | 459 に近づく | 何も無い |

一般国道の番号は 1〜58 と 101〜507 から廃止 6 番を除いた 459 個である。全国で見ればどの番号もどこかに実在するので、全国をひとまとめに判定した瞬間に絞り込みは空振りする。

取得元を Overpass から pbf に替えても、判定の単位は都道府県のままにしてある。取得は全国、判定は県である。

## 海上区間

「海上区間」と述べているものは航路として扱う。`route=ferry` が付いていなくても同じである。

読み取る欄は四つである。

| 欄 | 例 |
| --- | --- |
| `name`・`name:ja` | `国道58号(海上区間）` |
| `description`・`note` | `海上区間。フェリーは未供用。` |

名称だけでは足りない。全国で「海上区間」と書いた way は 34 本あり、内訳は次のとおりである。

| 書いてある欄 | way |
| --- | --- |
| 名称 | 20 |
| `description`・`note` だけ | 14 |

後者は前者の言い換えではなく、別の路線である。名称だけを読むと 16・28・30・42・57・259・317・324 号が車道のまま海の上に出る。

`route=ferry` だけを根拠にすると、さらに 12 路線で破れる。全国で計測した結果を示す。

| 描かれ方 | アーク | 延長 |
| --- | --- | --- |
| 車道 | 20 | 1,390.5 km |
| 航路 | 2 | 63.3 km |

海上国道を破線で描くのは、車道と紛れさせないためである。295 km の直線を実線で引けば、走れる道に見える。

## 未開通

`highway=planned`・`proposed` は道がまだ無い。ルートリレーションの連続性を保つために引かれた直線で、走れない。

全国で 86 アーク、173.3 km ある。内訳は `proposed` が 76、`planned` が 10 である。最長は国道 360 号の 16.4 km（白山白川郷ホワイトロードが代替路）、次いで国道 274 号の 16.1 km（`description=国道274号不通区間`）である。

`kind` を分けず `road` のまま出すと、16 km の直線が実線で引かれ、走れる道に見える。海上区間を破線にしたのと同じ理由である。

判定は海上区間のチェックより後に置く。「海上区間」と書いた 34 本のうち 32 本は `highway=planned` を持つ。`highway` を先に見ると、直したばかりの海上国道が未開通として上書きされる。

## 旧道

名称に「旧道」「廃道」「旧国道」を含むものは `former` フラグを立てて残す。除外しない。

- 指定解除まで法令上は国道である
  - 解除は開通から数年遅れる
- 地理院地図も同じ理由で国道として描き続ける
- OSM は実態を反映して指定を外す傾向がある

名称も `ref` もリレーション所属もすべて外された旧道は、OSM から復元できない。

## 自動車専用道路

`highway=motorway` の区間は `kind=expressway` にする。第二神明道路や神戸淡路鳴門自動車道のように、国道番号とは別に高速道路としての路線番号（`ref=E93;2` の `E93`、`ref=C3;475` の `C3` など）を持つ区間である。

車道であることは変わらないので、点線国道や工事中のような破線扱いにはしない。別の種別にするのは、平面交差の無い自動車専用の道路が、ふつうの平面国道とは別物として利用者の目に映るからである。表示・非表示を切り替える口も別に持たせる。

判定は `highway=motorway` かどうかで決め、`ref` の書式では決めない。全国で計測すると、`E` や `C` などの番号と `motorway` が両方揃うもの 6,321 本に対し、`motorway` だが番号の頭文字が違うもの（`C3`・`A1` など）が 6,619 本ある。`ref` の書式で判定すると後者を取りこぼす。逆に番号だけあって `motorway` でないもの 199 本は全て `construction=motorway`（建設中）で、`construction` の判定が先に効くので問題にならない。

## 出力の属性

| 属性 | 意味 |
| --- | --- |
| `refs` | 区切り文字で囲んだ指定路線。例は `,18,117,406,` |
| `refs_list` | 同じ内容の配列 |
| `n` | 重用数 |
| `kind` | `road`、`expressway`、`construction`、`unopened`、`foot`、`steps`、`ferry` |
| `src` | 判定の根拠。`relation`、`name`、`tag` |
| `former` | 旧道なら 1 |
| `updated` | その区間の最終編集日 |

`refs` を区切り文字で囲むのは、番号の照合を文字列包含で書けるようにするためである。`,4,` は `,14,` や `,400,` に誤マッチしない。
