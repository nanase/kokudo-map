# readable-japanese — 読みやすい日本語

日本語の文章を、読み手が引っかからずに読める状態に整える作法である。文体・語彙・記法の乱れを直す。適用対象はドキュメント、コード内のコメント、Issue、PR、コミットメッセージなど、日本語を書く場所全般である。

## 手を入れない箇所

そのまま出力・使用される固定文字列は推敲しない。文言を変えると挙動や例の意味が変わるためである。

- コマンド・コード
- 出力テンプレート、サブエージェントへ渡すプロンプト
- わざと悪い例を見せている引用や before/after の例

## 語尾の統一

文書中で「です・ます」調と「だ・である」調を混ぜず、必ずどちらかに統一する。

## 体言止め

通常の文では体言止めを避ける。文末は述語で締める。要約やリード文、description のような説明文も通常の文として扱い、体言止めにしない。体言止めは次の箇所でのみ使う。

- タイトル
  - セクション名を含む
  - コミット名
- 箇条書き

## 一般的でない語彙

辞書にはあり意味も正しいが、一般の文書に馴染まない語は、より平易な語に直す。英単語を直訳して日本語として不自然になった語も同じく直す。

- 病理 → 原因 / 症状
- 出荷 → 投稿
  - ship の直訳
  - この文脈では「投稿」が適切
- 瑣末・些末 → 些細 / 軽微

## 箇条書き

- 原則として体言止め
- 体言止めが不自然になるときは最小限の文を許容
  - 「〜しない」の形
- 末尾に「。」を付けない
- 装飾としての太字を使わない
- 1 項目に複数の文を詰めない
  - 収まらないときは入れ子にして分ける
  - 入れ子は 2 段までに留める
- 番号付きリストも同じく末尾に「。」を付けない
  - 順序を表すので、体言止めにせず「〜する」の述語形で書く

長い文を入れ子で分ける例を示す。

```
元の文章:
- 妥当な指摘: 対応する。相違がなければ返答不要。
- 対応しない指摘: 理由を当該スレッドに返す。
- スコープ外修正: 別 PR を検討する。当該 PR で「ついで修正」しない。

読みやすい例:
- 妥当な指摘
  - 対応
  - 相違がなければ返答不要
- 対応しない指摘
  - 当該スレッドにて理由を返答
- スコープ外修正
  - 別 PR を検討
  - 当該 PR で「ついで修正」しない
```

## 括弧の使用

括弧は必要最小限に留める。読み手が見落とすと困る情報は、括弧に入れず独立した文にする。

## 判断に迷うとき

迷ったときは自分だけで決めず、書き手に質問して確認する。次のような場面が該当する。

- 平易な語への言い換えで、文脈に最も合う語を選びきれないとき
- 規則を適用すべきか、例外として残すべきか判断がつかないとき
