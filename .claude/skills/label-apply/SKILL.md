# label-apply — Issue / PR に分類ラベルを付ける

Issue / PR を出す直前に、その時点のラベル定義を読んで付けるラベルを判断し、付ける。固定の対応表は持たない（ラベルは時々で変わるため、毎回読む）。

合うラベルが無ければ付けない。誤分類のコストは付け忘れより大きいので、迷ったら付けない。

## 手順

1. 付与の直前に `scripts/list-labels.sh` でラベル一覧（名前・説明・色）を取る
2. 各ラベルを「主題か」で判定し、当てはまるものだけ付ける
   - 説明文の範囲で判定
   - ラベル名は見出しにすぎない
   - 「触れている」でなく「主題である」かで見る
   - 説明文が限定する対象に触れていなければ、語感が近くても付けない
   - 迷ったら付けない
3. 付けると判定したラベルを対象へ付与し、結果を確認する
   - Issue: `gh issue edit <番号> --add-label "<name>"`
   - PR: `gh pr edit <番号|URL|ブランチ> --add-label "<name>"`
   - 付与後は `gh issue view` / `gh pr view` の `--json labels` で反映を確認する

## 出力

- 付けたラベル（無ければ「付けない」）
- 見送り理由があれば一言
  - Issue / PR 本文には書かない
